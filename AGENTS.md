# Инструкция для агента, который поднимает этот проект

Личный дашборд крипто-портфеля на Next.js. Не сервис с аккаунтами: каждый клонирует репозиторий и запускает свою копию. Все данные пользователя лежат в `data/` рядом с кодом, наружу не уходят и в git не попадают.

## Поднять с нуля

Требуется Node 20.9+.

```bash
npm install
cp .env.example .env.local     # можно оставить пустым — дашборд работает без ключей
npm run dev                    # http://localhost:3500
```

Проверка, что всё живо:

```bash
curl -s localhost:3500/api/health | head -40   # конфиг и свежесть кэшей
npm run warm                                    # прогреть кэши (сервер должен быть запущен)
```

Прод:

```bash
npm run build && npm start     # порт 3500
# либо
docker compose up -d --build
docker compose --profile cron up -d   # плюс контейнер с запуском агента по расписанию
```

## Никаких ключей для старта не нужно

Работает сразу, без регистраций: CoinGecko (цены, профили монет), DeFiLlama (пулы, протоколы, взломы, стейблкоины, история цен), Binance (стакан, свечи, фондирование), DexScreener (DEX-ликвидность), новостные RSS и поиск Bing News, индекс страха и жадности.

Ключи только добровольные, и все настраиваются **в интерфейсе**, не в файлах:

| Что | Где вводится | Что даёт |
|---|---|---|
| Bot token + chat id Telegram | страница «Агент» → «Канал доставки» | сводки в Telegram; кнопка «Проверить бота и найти чат» сама находит chat id |
| Ключ ASCN Crypto API | страница «Агент» → «ИИ-разбор токенов» | разбор ончейна, сантимента и ликвидаций по токену; без ключа агент присылает сводку по своим метрикам |
| Demo-ключ CoinGecko | `COINGECKO_API_KEY` в `.env.local` | снимает лимит 5–15 запросов в минуту у публичного API |
| `AGENT_SECRET` | `.env.local` | нужен только если разбор дёргают извне: `POST /api/agent/run?secret=…` |

Ключи, введённые в интерфейсе, ложатся в `data/settings.json`. Этот каталог в `.gitignore` — коммитить его нельзя.

## Что не надо делать

- **Не коммитить `data/` и `.env.local`** — там портфель, токен бота и ключ ASCN.
- **Не переносить хранение в БД** ради «правильности»: это личная установка, файлы здесь уместны и запись сериализована по файлу.
- **Не звать ИИ-разбор синхронно из запроса** — один токен отвечает 3–6 минут. Запуск идёт фоновой задачей: `POST /api/agent/run` отдаёт `202`, прогресс в `GET /api/agent/job`. Для внешнего планировщика есть `?wait=1`.
- **Не давать рекомендаций** в текстах интерфейса и в промпте ассистента. Дашборд излагает факты, решение принимает человек: состояние позиции описывается как «Тренд сломан» или «Слабее рынка», а не «продавать».
- **Не показывать внутренний балл 0–100** — наружу идёт уровень риска словами.
- **Не тянуть в клиентские компоненты модули с `fs`**: чистое форматирование индикаторов вынесено в `lib/indicators-view.ts` именно поэтому.

## Как устроено

```
src/lib/        данные и логика: market, coinmeta, yields, liquidity, indicators,
                news, hacks, context, history, score, analyze, agent, ascn, scheduler
src/app/        три страницы (портфель, риски, агент) и API-роуты
src/components/ карточки, дровер токена, редактор портфеля, график
data/           портфель, настройки, снимки, история запусков, кэши источников
scripts/        run-agent.mjs (запуск разбора), warm.mjs (прогрев кэшей)
```

Полное описание источников, формулы риска и логики выбора пулов — в `README.md`.
