# ASCN.AI Portfolio — стейкинг, риски и агент

Дашборд по крипто-портфелю: где стейкать каждый токен и под сколько, какие токены слабые и что с ними делать, плюс агент, который дважды в день присылает в Telegram только изменения.

Дизайн-система — та же, что в дашбордах продажника и рассылки (`ascn-broadcast-dashboard`): светлая тема, `--blue #4d5ff6`, сайдбар 248px, `metric-card`, Geist + lucide-react.

Каждый запускает свою копию у себя: это не сервис с аккаунтами, а личный дашборд. Портфель, настройки и кэши лежат в `data/` рядом с кодом и никуда не уходят.

## Запуск с нуля

Нужен Node 20.9 или новее.

```bash
git clone <репозиторий> && cd crypto-agent
cp .env.example .env.local
npm install
npm run dev
```

Открыть http://localhost:3500 — портфель пустой, добавить токены через «＋ Мои токены» (поиск по тикеру или названию) или нажать «Посмотреть на демо-портфеле». **Ни одного ключа для этого не нужно**: цены, доходности, ликвидность и новости берутся из публичных API.

Полезное после клонирования:

```bash
npm run warm     # прогреть кэши, чтобы первое открытие не ждало внешние API
npm run health   # что подтянулось, что просрочено, чего нет в конфиге
```

### Docker

```bash
cp .env.example .env.local
docker compose up -d --build              # дашборд на http://localhost:3500
docker compose --profile cron up -d       # плюс агент: разбор в 9:00 и 21:00
```

Каталог `data/` смонтирован как том — портфель и настройки переживают пересборку образа. Порт меняется переменной `HOST_PORT`.

### Что задаётся в `.env.local`

```
TELEGRAM_BOT_TOKEN=   # @BotFather → /newbot
TELEGRAM_CHAT_ID=     # @канал (бота добавить админом) или id чата
AGENT_SECRET=         # защита cron-эндпоинта
COINGECKO_API_KEY=    # рекомендуется: бесплатный demo-ключ, 30 запросов/мин
```

Ничего из этого не обязательно: без Telegram агент просто скажет, что канал не настроен, без ключа CoinGecko будет работать на публичных лимитах.

**Про лимиты CoinGecko.** Публичный API без ключа держит ~5–15 запросов в минуту, а один разбор портфеля из 5 токенов делает ~11 запросов (цены, поиск тикеров, профили монет). Все запросы идут через очередь с паузой и повтором на 429, профили кэшируются на 24 часа — но при первом холодном запуске часть профилей может подтянуться только со второй попытки. Бесплатный demo-ключ (coingecko.com → Developers → Demo API key) снимает проблему полностью.

Telegram настраивается на странице «Агент», без правки файлов (настройки лягут в `data/settings.json`):

1. `@BotFather` → `/newbot` → скопировать токен, вставить в поле **BOT TOKEN**;
2. написать своему боту `/start` в личку (или добавить его админом в канал и что-нибудь туда отправить);
3. нажать **«Проверить бота и найти чат»** — дашборд спросит у Telegram, кто боту писал, и подставит `chat id` сам;
4. **«Сохранить»**, затем **«Тест сообщения»** — должно прийти в Telegram.

## Страницы

| Страница | Что делает |
|---|---|
| `/` | Портфель: график стоимости за 7Д / 30Д / 90Д / 1Г с подсказкой под курсором, донат аллокации с индексом страха и жадности, метрики, сигналы агента и позиции — карточками или таблицей (переключатель, выбор запоминается). Клик по токену → дровер с вкладками «Заработать», «Разбор», «Профиль», «Новости», «Выход и хедж» (там ёмкость выхода, лестница стакана, DEX-пулы и площадки со спредами) |
| `/risks` | Рейтинг риска от худшего к лучшему: аргументы «против» и «за» с весами и план действий |
| `/agent` | Настройка Telegram, ручной запуск, расписание, **состояние установки** (конфигурация и свежесть каждого источника) и история запусков с текстом сводок |

| Новости по токенам | RSS: Cointelegraph, CoinDesk, Decrypt, CryptoSlate | не нужен |

Всё кэшируется на диск в `data/`: пулы 30 мин, протоколы 24 ч, цены 5 мин, стакан 5 мин, DEX-пулы 15 мин, фондирование 15 мин, новости 20 мин, площадки 30 мин, индекс страха 1 ч, история портфеля 1 ч, история пула 6 ч, стейблкоины 6 ч, профили монет / взломы / комиссии 24 ч. Если источник упал — отдаётся последнее удачное значение.

**Платные ручки, которые не подключены:** `api.llama.fi/emissions` (календарь разлоков) и `api.llama.fi/raises` (раунды) отдают 402 на бесплатном тарифе — поэтому давление разлоков считается по прокси «доля в обороте». GitHub API без токена лимитирует по IP, dev-активность не тянем.

**Метаданные видны там, где нужны решения:** на карточке — логотип, ранг `#214`, категории и сети; в дровере — вкладка «Профиль» с описанием, ссылками (сайт, X, эксплорер, GitHub, CoinGecko) и контрактами по каждой сети с копированием; в редакторе портфеля — под каждым тикером показано, какую именно монету подставил CoinGecko (`ApeCoin #214 · apecoin`), и кнопка «не тот токен?» со списком кандидатов. Тикеры не уникальны: по запросу `APE` есть и ApeCoin, и Ape and Pepe с более высоким рангом — поэтому точное совпадение тикера всегда идёт первым, а выбранный `coinId` сохраняется в портфеле.

## Как считается health (0–100)

Семь блоков, каждый даёт свой вклад — на вкладке «Разбор» видно, из чего собрался балл:

| Блок | Вес | Смысл |
|---|---|---|
| Динамика против рынка (7д, 30д) | 25 | падает ли токен сильнее BTC/ETH — это про токен, а не про рынок |
| Абсолютный тренд 30 дней | 10 | направление цены |
| Структурный тренд (200д, 1г) относительно рынка | 15 | долгое отставание — не просадка, а история |
| Ликвидность выхода | 10 | реальная глубина стакана Binance + DEX-пулов против размера **вашей** позиции; прокси «объём / капитализация» только если стакана нет |
| Новостной фон | 18 | тон заголовков по ключевым словам, от −3 до +3 |
| Просадка от максимума + давность хая | 12 | −99% пять лет назад ≠ −99% в этом году |
| Разлоки (в обороте / всего) | 8 | сколько сапплая ещё придёт в рынок |
| Есть ли надёжный стейкинг | 2 | актив без доходности лежит мёртвым грузом |

Плюс жёсткие правила, которые перебивают математику:

- **критичная новость** (взлом, скам, делистинг, закрытие проекта, депег, остановка выводов) → балл ≤ 22 и вердикт «продавать»;
- **структурно сломанный актив** (≤ −95% от хая, минус за год, минус за 200 дней) → балл ≤ 36;
- **обвал за сутки** ≥ 15% → −10;
- **взлом самого проекта** за последние 2 года → −4, а если вынесли больше $10M → −7.

Вердикты: <28 продавать · <42 сокращать · <56 наблюдать · <72 держать · ≥72 держать и стейкать.

## Как выбирается «куда поставить»

Верхний вариант — не максимальный APY, а устойчивый:

- спот-ставка подрезается средней за 30 дней (`apyMean30d × 1.3`) и ограничивается сверху — 500% в тонком пуле не должны выигрывать у Lido;
- риск 1–5 считается по TVL, impermanent loss, доле наградных токенов, флагу `outlier` и категории протокола;
- LP получает штраф: это другой продукт — нужен второй актив и есть IL;
- история взломов протокола повышает риск соразмерно инциденту: вынос от $10M — это +2, утечка на $300K — только пометка в карточке;
- по каждому пулу доступна история ставки за полгода с медианой и диапазоном за 90 дней, плюс комиссии протокола за 30 дней — видно, зарабатывает он на пользователях или живёт на эмиссии;
- в заголовок («поставить под X%») попадает только **однотокенный** вариант с риском ≤3, TVL ≥ $1M и APY ≥ 1%. Если такого нет — так и написано: «надёжного варианта нет», а агрессивные пулы показаны отдельным блоком.

Из этого же считается KPI «Потенциал стейкинга» — по надёжным вариантам, а не по самым жирным.

## Агент и расписание

Агент сравнивает текущий разбор со снимком прошлого запуска (`data/last-snapshot.json`) и отправляет только дельту: смену вердикта, изменение health на 12+, движение цены на 12%+, новые плохие и хорошие новости, рост ставок стейкинга на 3+ п.п. Если важного нет — молчит (переключается галочкой «присылать сводку всегда»).

Два запуска в день через crontab (`crontab -e`). У cron минимальный `PATH`, поэтому путь к node — абсолютный (`which node`), а вывод стоит писать в лог:

```
0 9 * * *  cd "/path/to/crypto-agent" && /usr/local/bin/node scripts/run-agent.mjs >> "/path/to/crypto-agent/data/agent-cron.log" 2>&1
0 21 * * * cd "/path/to/crypto-agent" && /usr/local/bin/node scripts/run-agent.mjs >> "/path/to/crypto-agent/data/agent-cron.log" 2>&1
```

Дашборд при этом должен быть запущен — скрипт дёргает его по HTTP. Проверить, что планировщик работает, не дожидаясь 9 утра: добавить временную строку `* * * * *` с той же командой, через минуту посмотреть `data/agent-cron.log` и убрать её. В логе должна появиться строка вида `портфель $10578, сигналов 6, telegram: отправлено`. На macOS каталог `~/Documents` защищён — если лог не появился, дайте `/usr/sbin/cron` доступ в System Settings → Privacy & Security → Full Disk Access.

Или из любого планировщика:

```
curl -X POST "http://localhost:3500/api/agent/run?secret=$AGENT_SECRET"
```

## Хранение и надёжность

Файловое, без БД: `data/portfolio.json`, `settings.json`, `last-snapshot.json`, `agent-runs.json` (последние 60) и кэши источников. Запись сериализована по файлу с уникальным `.tmp`, чтобы параллельные апдейты не теряли данные. Битый или отсутствующий файл кэша не ломает работу — читается как «нет данных».

Что сделано, чтобы дашборд не падал на чужой машине:

- **у каждого источника свой лимит времени**, а у всего разбора — общий дедлайн 55 секунд. Что не успело — отмечается в `warnings`, страница показывает жёлтый баннер «данные неполные» и работает на остальном;
- **ни один источник не критичен**: нет цен — токен покажется без метрик; нет пулов — не будет доходностей; нет новостей — скор посчитается по цене, ликвидности и разлокам;
- **источник упал, а кэш есть** — отдаётся последнее удачное значение вместо ошибки;
- **пустой портфель** — валидный сценарий: страница открывается, ничего не считается, предлагается добавить токены;
- **`/api/health`** отдаёт конфигурацию и свежесть каждого кэша (тот же блок виден на странице «Агент»);
- **свежая установка не содержит чужих позиций** — демо-портфель подгружается только по кнопке.

## Ограничения

- Портфель вводится руками; подключения кошелька по адресу пока нет.
- Тикеры разрешаются автоматически (точное совпадение + лучший market cap rank); если подставилась не та монета — выбрать нужную в «Мои токены» → «не тот токен?».
- Дашборд не знает, что уже застейкано: «потенциал» считается со всей позиции.
- Ёмкость выхода для DEX — оценка: сдвиг цены v2-пула на 1% принят за 0.25% его TVL, для concentrated liquidity это консервативно.
- График за 30/90/365 дней — это текущие позиции по историческим ценам, а не реальная история сделок (о чём подписано под графиком).
- Новостной тон — по ключевым словам в заголовках (RU/EN), не LLM. Ошибается на иронии и заголовках-вопросах.
- Не инвестиционная рекомендация: это калькулятор публичных данных.
